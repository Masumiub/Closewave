# Closewave Landing Page

A modern, responsive, and high-conversion landing page for **Closewave**, a Sales Intelligence platform. 

Closewave listens to sales conversations and whispers the right move in real time — offering objection handling, competitor talk tracks (battlecards), and CRM updates that write themselves. This landing page is built to showcase these capabilities effectively and drive user sign-ups.

## Goals
- **Product Showcase**: Clearly communicate the core value proposition of real-time sales intelligence.
- **Conversion Optimization**: Drive user signups for the 14-day free trial through compelling copy, live demos, and clear calls-to-action (CTAs).
- **Modern User Experience**: Deliver a fast, responsive, and visually appealing experience using modern web technologies.

## Features & Sections
The landing page includes several dedicated sections to guide the user journey:
- **Hero & Live Demo**: A captivating hero section featuring a simulated "Live Call Demo" that shows how Closewave works in real-time during a sales call.
- **Social Proof**: Company logos and trust indicators.
- **Features & Showcase**: Detailed breakdowns of core functionalities like real-time objection handling and automated CRM syncing.
- **Benefits**: Value-driven points highlighting increased win rates and administrative time saved.
- **Testimonials**: Customer reviews and success stories.
- **Pricing**: Transparent pricing tiers.
- **FAQ**: Answers to common questions about setup, security (SOC 2 Type II), and usage.

## Tech Stack
This project is built using:
- **React 19**
- **Vite**
- **TypeScript**
- **TailwindCSS v4**

## How to Run Locally

To get the project running on your local machine, follow these steps:

1. **Navigate to the project directory:**
   Ensure you are in the root directory of the project (`sales-intelligence-landing-page`).

2. **Install dependencies:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View the app:**
   Open your browser and navigate to the local URL provided in your terminal (usually `http://localhost:5173/`).

## Building for Production
To build the app for production, run:
```bash
npm run build
```
You can preview the production build locally with:
```bash
npm run preview
```
